# Yardstick

Launch on pump.fun. See where you stand.

A free, non-custodial site for Solana creators: launch a coin on pump.fun from your own wallet, then compare it with other coins of the same age. No fees; mainnet only.

- Setup, deployment, environment variables and troubleshooting: [docs/YARDSTICK.md](docs/YARDSTICK.md)
- Method (metrics, comparison groups, composite score): the `/how` page

```sh
npm install
npm run dev
npm test
```
